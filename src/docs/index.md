# Портфолио студента

Добро пожаловать на сайт-портфолио студента **ИТМО**.

На сайте собраны лабораторные работы и учебные материалы по программной инженерии.

## Что находится на сайте

- информация об авторе;
- лабораторные работы;
- исходный код и результаты выполнения;
- выводы по каждой работе.

Сайт создан с использованием **MkDocs** и опубликован через **GitHub Pages**.
