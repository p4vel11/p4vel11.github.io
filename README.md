# Портфолио студента ITMO

Статический сайт-портфолио создан с помощью MkDocs и предназначен для размещения лабораторных работ по дисциплинам направления программной инженерии.

## Выбор темы

В работе используется тема **Material for MkDocs**. Она выбрана потому, что имеет удобную навигацию, поддерживает иерархическое меню, хорошо отображает исходный код и подходит для сайта-портфолио с несколькими лабораторными работами.

## Структура проекта

- `source/` — исходники сайта MkDocs;
- `source/mkdocs.yml` — конфигурация MkDocs;
- `source/docs/` — Markdown-страницы;
- `docs/` — сформированный статический сайт для GitHub Pages.

## Локальный запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install mkdocs-material
cd source
mkdocs serve
```

## Сборка

Из каталога `source`:

```bash
mkdocs build -d ../docs
```

После сборки каталог `docs` содержит готовый статический сайт.
